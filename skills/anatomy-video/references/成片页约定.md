# 成片页约定（cut/index.html）

成片页把多张 Anatomy 物件图（iframe）、左侧文字栏和字幕合成一个 1920×1080 的页面。照 `templates/composer_example.html`（第 01 集 H100）改，下面这些是工具依赖的约定，不能省。

## 必须提供

| 名字 | 作用 | 谁用 |
|---|---|---|
| `<script src="timeline.js">` → `window.TL` | 字级时间、句子、时长（make_timeline.py 生成） | 全部 |
| `window.render(t)` | 画出第 t 秒；只由 t 决定 | render.py、checks.py |
| `window.__total` | 总时长（秒） | render.py |
| `window.__ready = true` | 物件图和文字栏都准备好 | 全部 |
| `window.__bootFailed = true` + `missing` | 锚点找不到时启动失败 | 全部 |
| `A(词, n)` 记入 `window.__anchors` | 词在配音里第 n 次出现的时间 | preflight.py |
| `CUT(词)` 记入 `window.__cuts` | 该词所在句的句首前 0.2 秒 | preflight.py、sheet.py |
| 文字栏每行 `class="it"`，字幕 `#subs` | 文字检查 | checks.py |

## 写镜头时的规矩（每条都对应一个踩过的坑）

1. **每个镜头的 pose 必须完整重设它用到的物件的全部状态**：位置、展开、点亮、组装进度。不能沿用“上一次留下的样子”。
   闪回、片尾这种只摆位置的镜头也一样（第 01 集闪回里芯片变空就是这个）。checks.py 的无状态检查会抓。
2. **同一个零件只用一条点亮语句**：两条语句先后设置同一批零件，后一条会把前一条覆盖掉。要分情况就合成一个条件。
3. **切点锚点写句子开头的几个字**：`CUT("拆掉散热器")`。锚点写在句中，镜头会比这个词早很多切。
4. **锚点在配音里出现多次时写明第几次**：`A("九百吉字节", 2)`；不写就是第 1 次。preflight.py 会列出所有重复的锚点。
5. **镜头推近按“最大推近 × 4% 漂移”算边界**：配音时间变了，推近的时机和幅度也会变，所以推近后一律跑 checks.py 看出框。
6. **大镜头（物件铺满画面）出现前，文字栏先整组退场**：加一个空组 `G(时间, [])`。
7. **文字栏一行写不下时改短，不靠折行**：标题最后一行只剩一两个字算错误。
8. **实心体不用半透明**：要表示“不计入、关闭”，用 is-off 灰色画法。
