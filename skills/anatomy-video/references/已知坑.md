# 已知坑

每个坑尽量对应一项自动检查；做不成检查的才只写在这里。新坑写在最上面。

| 坑 | 后果 | 现在由谁拦 |
|---|---|---|
| 在一行代码中间插 `//` 注释，把后半行（含收尾括号）注释掉 | 页面脚本语法错误，所有工具都等到 5 分钟超时 | 行内说明用 `/* */`；common.py 一遇到页面脚本错误立刻停下并报出错误 |
| uv 每次运行都会联网查包索引；网络断了直接报错（tls handshake eof） | 工具全部跑不起来 | 包都已缓存在 F:/tools/uv-cache，断网时加 `uv run --offline` |
| 下载合成音频时网络中途断开 | 存下半截音频 | tts.py 重试 6 次，并核对时长不短于最后一个字 |
| 网页工具读 PDF 会把文件缓存到 C 盘（`~/.claude/projects/…/tool-results/webfetch-*.pdf`） | 违反“C 盘不占用”；子 agent 调研时也会触发 | 调研结束后检查该目录，把 PDF 移到本集 research/pdf（有用的官方文件正好留档） |
| 闪回、片尾镜头只摆位置不重设姿态 | 分块并行渲染时，画面随“上一次画了什么”变化（第 01 集闪回里芯片变空） | checks.py 无状态检查 |
| 帧指纹用整张截图的 md5 | 抗锯齿造成的单个像素差 1 级，被当成“变了” | render.py 改用缩略图量化指纹 |
| Git Bash 把以 / 开头的参数改写成 C:/Program Files/Git/… | 封面页找不到物件图，一直等到超时 | cover.py 接受相对路径并自动纠正 |
| 4 个浏览器同时启动、各加载 9 张物件图 | 互相拖到超时，只剩 2 路在渲染 | render.py 浏览器逐个启动 |
| uv 不写 playwright 版本会拉新版，新版要找别的浏览器版本 | 找不到浏览器，直接报错 | 统一 `--with playwright==1.63.0`；doctor.py |
| 系统临时目录在 C 盘 | 浏览器临时配置写进 C 盘 | common.py 把本进程的临时目录指到 F:/tools/tmp |
| 切点按“句首到句尾 ±0.05 秒”找句子，前后句挨着时取到前一句 | 10 个切点 7 个提前一句，一段内容整段丢失 | preflight.py 切点核对 |
| 两条点亮语句先后设置同一批零件 | 后一条把前一条关掉，该亮的不亮 | 只能看抽帧；成片页约定第 2 条 |
| 配音时间一变，旧的推近参数就推出画面 | 出框、压文字栏 | checks.py 出框 |
| 分段合成配音 | 前后音色、语气不一致，用户一听就出来 | 规范：全片一次合成 |
| 型号直接写 H100、单位写 GB | 念成“H10百”“G B” | terms.py 禁用写法 |
| 语音识别对齐时把整篇稿子当提示词 | 识别出幻觉，时间全乱 | 已不用识别对齐，改用引擎字级时间 |
| 流式合成接口的 words 为空 | 拿不到字级时间 | tts.py 用异步接口 |
| 物件页的内联脚本里出现 `</script` | 整页 HTML 被截断 | Anatomy 构建脚本统一转义 |
| 物件图里的函数和 Anatomy 工具包重名（如 rise） | 页面报错 | 构建时报错即可发现 |
| 叠化正中间两张物件图半透明重叠 | 有重影，严格看不干净 | 没有自动检查；sheet.py 转场图上看。可改进项 |
