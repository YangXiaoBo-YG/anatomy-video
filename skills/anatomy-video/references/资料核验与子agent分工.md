# 资料核验与子 agent 分工

用于新选题、新型号、技术参数变化，以及脚本或画面新增技术断言。先完成本流程，再锁定配音。局部改字且不改变事实时，不必重做整轮研究。

## 1. 主 agent 先定义核验范围

明确产品名、芯片代号、版本、时间截点和这一集要解释的问题。例如 H100 SXM 80GB 与 H100 PCIe、H100 NVL 分别建条目，不将其参数合成一张产品规格。

列出需要证明的断言并分配 ID：数字、日期、结构关系、比较结论、原理解释和画面会暗示的事实。画面里有几个堆栈、管线接到哪里，与旁白里的参数一样需要证据。

## 2. 子 agent 并行调查，主 agent 汇总

具备子 agent 工具时，按选题复杂度拆成以下工作包；小选题可以合并，不要求固定人数。子 agent 只读取资料、提交证据，不自行改正式稿、运行收费模型或发布内容。

| 工作包 | 调查内容 | 必须返回 |
|---|---|---|
| 产品规格 | 型号、容量、算力、带宽、功耗、发布与出货日期 | 官方规格链接、版本、表格或章节位置、单位及适用条件 |
| 架构与机制 | 白皮书、架构图、互联拓扑、单元数量、工作原理 | 原始材料定位、完整设计 / 实际启用的区别、可以与不可以推出的结论 |
| 结构与视觉 | 图纸、官方实物图、拆解材料、封装与接口布局 | 图号 / 页码、尺寸依据、真实结构与示意的边界 |
| 独立复核 | 对照上述断言回查原文、找冲突、复算数字 | 逐项支持 / 部分支持 / 不支持、冲突原因、修订建议 |

独立复核者应直接打开原始资料，不把其他 agent 的摘要或“已确认”结论当证据。先形成自己的判断，再比较调查结果。主 agent 对最终采用的表述负责；多名 agent 赞成不等于核实。

没有子 agent 工具时，由主 agent 分轮完成相同工作，并记录“单 agent 顺序复核”，不能声称进行了独立多 agent 验证。

### 调查任务模板

> 核验对象：{产品与版本}，时间截点：{日期}。核验问题与断言 ID：{列表}。
> 优先读取厂商规格、白皮书、官方开发文档、原始论文或标准。
> 每项返回：断言 ID、结论、具体型号、单位与口径、来源 URL、标题与版本日期、页码 / 表号 / 章节、支持该结论的短摘录或精确转述，以及不确定之处。
> 搜索摘要只作为线索。打不开原文时标“未核验”，不凭记忆补齐。不得获取或传递个人密钥、账号配置、签名媒体链接。

### 独立复核任务模板

> 根据断言清单和原始来源，独立核验技术准确性。先自行判断，再比较已有结论。
> 检查型号混用、单位换算、单双向、单卡 / 整机、理论 / 实测、稠密 / 稀疏、发布日期 / 出货日期及图像推断。
> 输出逐项判定、证据位置、复算过程和可安全使用的措辞。不要只润色文字，也不要将多个转载视为独立来源。

## 3. 证据规则与口径检查

- 优先采用型号级官方规格和白皮书；机制可用官方架构文档或原始论文，测量值保留原始研究的测试条件。
- 多个来源转述同一材料只算一条证据。官方单一来源也可采用，但写明版本与支持范围，不为凑数量使用转载。
- 第三方拆解可支持外观或测量，不自动等同于厂商确认。单张外观图不能证明内部材料、堆叠层数或电路功能。
- 比较前统一：精度、稠密 / 结构化稀疏、单双向、单 GPU / 封装 / 整机、峰值 / 持续值、配置和测试任务。
- 复算需写公式和单位，例如“启用 SM 数 × 每 SM 单元数”；取整后的峰值比例写“约”，不声称数学上精确翻倍。
- 峰值吞吐增长不能直接推出实际模型速度同倍增长；理论结构说明不能自动推出该产品的具体物料。
- 不确定结构标为示意，尤其是未启用单元的位置、未知 HBM 位置内部结构和逻辑互联线。逻辑连线不得标成真实 PCB 走线。

## 4. 记录与裁决

每集使用 `templates/参数口径表.md` 建立证据表，并保存 `research/核验记录.md`。资料放项目目录，遵守用户的磁盘要求；不把含凭据的请求、私人文件或付费资料上传到公开仓库。

每项有且只有一种状态：

| 状态 | 可用于何处 |
|---|---|
| 已核验 | 可进入旁白、字幕和画面；保留必要限定条件 |
| 有据推导 | 写明依据、公式和假设；不得冒充官方原始规格 |
| 建模示意 | 可用于明确标注的示意画面，不作为已确认实物细节讲述 |
| 来源冲突 | 保留各版本与差异，不擅自取较大值或较新值拼表 |
| 待核验 | 不进入确定性旁白与参数字幕；可删除该细节或明确说明未知 |

主 agent 回读关键原文、检查复算、裁决冲突，并将断言 ID 映射到稿件句子和镜头。来源未解决时调整措辞、删去断言或标明未知；只有冲突会改变核心讲法且无法自行裁决时，才请用户决定取舍。不要把查资料工作转交给用户。

## 5. 进入制作前的检查

1. 稿中每个核心数字、比较和机制说明可回溯到断言 ID 与原始资料。
2. 旁白、字幕和画面使用同一版本、同一口径；示意说明已进入对应镜头。
3. 独立复核意见已处理，未解决项仍保留未解决状态。
4. 确认资料核验和自动几何审计是两种检查：几何审计通过只证明画法自洽，不证明硬件事实正确。
5. 配音锁定后修改参数，记录受影响的句子、字幕、物件、镜头和时间轴，再决定重做范围。

输出完成才进入试读与配音锁定。公开项目介绍可以描述本工作流的能力；没有实际运行记录，不得声称某一集已经执行多 agent 核验或通过了事实审查。
